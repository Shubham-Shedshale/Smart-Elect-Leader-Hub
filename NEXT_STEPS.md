## 🚀 How to Run (Choose One)

### Option 1: VS Code (Recommended - Easiest)
1. **Double-click `easy-run.bat`** 
2. Choose option **2** (Open in VS Code)
3. VS Code will open automatically
4. Press `Ctrl+Shift+P` → Type "Spring Boot: Run Application"
5. Select `ElectronicVotingSystemApplication.java`

### Option 2: Manual VS Code Setup
1. Open VS Code
2. Install extensions: "Spring Boot Extension Pack" + "Language Support for Java"
3. File → Open Folder → Select your `ELECTRONIC VS` folder
4. Press `Ctrl+Shift+P` → "Spring Boot: Run Application"
5. Select `ElectronicVotingSystemApplication.java`

### Option 3: Install Maven (Advanced)
Follow the instructions in `RUN_GUIDE.md` to install Maven for command-line usage.

## 🌐 Access Your Application

- **Main App**: http://localhost:8080
